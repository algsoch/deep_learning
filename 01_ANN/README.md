# Artificial Neural Network (ANN) Project

## Overview
This project demonstrates the implementation of an Artificial Neural Network (ANN) from scratch and using popular frameworks.

## Theory
Artificial Neural Networks are computing systems inspired by biological neural networks. They consist of:
- **Input Layer**: Receives the input features
- **Hidden Layers**: Process information through weighted connections
- **Output Layer**: Produces the final prediction
- **Activation Functions**: Introduce non-linearity (ReLU, Sigmoid, Tanh)
- **Backpropagation**: Algorithm for training by adjusting weights

## Project Structure
- `ann_from_scratch.py`: Implementation of ANN from scratch using NumPy
- `ann_tensorflow.py`: Implementation using TensorFlow/Keras
- `ann_pytorch.py`: Implementation using PyTorch
- `data/`: Sample datasets for training

## Use Cases
- Classification problems (binary and multi-class)
- Regression tasks
- Pattern recognition

## How to Run
```bash
# From scratch implementation
python ann_from_scratch.py

# TensorFlow implementation
python ann_tensorflow.py

# PyTorch implementation
python ann_pytorch.py
```

## Key Concepts Demonstrated
1. Forward propagation
2. Backward propagation
3. Gradient descent optimization
4. Loss functions (MSE, Cross-entropy)
5. Activation functions
